# Rayfield Gen 2 Modded — Corrected Feature Request

Please study the existing Rayfield Gen 2 source and preserve its current architecture, naming conventions, visual style, and public APIs. Do not rewrite or minify unrelated modules. Every new feature must be optional, backward-compatible, guarded against missing executor APIs, and free of nil function calls.

## Themes

Add three built-in themes with the same complete theme shape as the existing themes:

1. **Damacus** — a purple and blue theme.
2. **Blahite** — a black and white theme.
3. **Yelue** — a yellow and blue theme.

Theme lookup must be case-insensitive and must safely fall back to the default theme if a theme is missing or malformed.

## Image sources

Make image handling reliable for numeric Roblox asset IDs, `rbxassetid://`, `rbxasset://`, `rbxthumb://`, direct HTTP/HTTPS `.png`, `.jpg`, and `.jpeg` URLs, and Imgur links. Normalize Imgur page links to a direct image URL where possible. External downloads must use the library's filesystem and asset-resolver abstractions, never an undefined alias. If an executor does not provide `getcustomasset`, keep the original URL instead of throwing an error. Async Roblox avatar downloads must update the ImageLabel through a guarded callback.

## Hold buttons

Expose `Tab:CreateHoldButton` with `HoldTime`/`holdTime`, optional `LineColor`/`lineColor`, and a callback that runs only after the hold completes. Releasing early must cancel the callback and reset the progress indicator. The callback must run through the library's guarded callback path.

## Automatic blur

Blur should be automatic: opening/showing the window enables it, closing with the X disables it, and unloading destroys it. Minimize/restore must not accidentally remove blur while the window remains open. The implementation must be idempotent and must not require a `BlurBackground = true` option.

## Capsule animation

Find the capsule/hold interaction component and add a subtle smooth breathing animation while it is pressed or held. Do not add visible strokes to an otherwise invisible capsule. Stop and reset the animation on release, cancellation, destruction, or unload.

## Tab icon rotation

When `TabIconAnimation = true`, selecting a tab rotates its icon exactly one full turn from 0 to 360 degrees and then resets it to 0. If the option is absent or false, no rotation should occur.

## Profile window

When `ProfileWindow = true`, create a separate Rayfield-style profile card attached to the left side of the main window. It must remain parented to the window so it follows dragging, resizing, minimizing, restoring, and unloading. Display the local player's Roblox thumbnail, display name, `ProfileDescription`, and a clickable `Profilelink`. Copying the link must be guarded when clipboard APIs are unavailable.

Example:

```lua
local Window = Rayfield:CreateWindow({
    Name = "Example",
    Theme = "Damacus",
    ProfileWindow = true,
    ProfileDescription = "yooooooooo",
    Profilelink = "discord.gg/example",
    TabIconAnimation = true,
})
```

## Validation requirements

Before publishing, check every new public method exists, check all three themes resolve, verify no undefined filesystem aliases remain, and verify every optional callback/API is guarded with type checks or `pcall`.


## New feature usage

```lua
local Window = Rayfield:CreateWindow({
    Name = "Rarity Showcase",
    Theme = "Default",
    ThemeAnimation = {"Cobalt", "Default"},
    TransitionTime = "5 seconds",
    ShinyEffect = true,
})

local Tab = Window:CreateTab({Name = "Rewards"})

Tab:CreateDropdown({
    Name = "Reward rarity",
    Options = {
        {Name = "Common", Color = Color3.fromRGB(190, 190, 190)},
        {Name = "Rare", Color = Color3.fromRGB(80, 160, 255)},
        {Name = "Epic", Color = Color3.fromRGB(190, 90, 255)},
        {Name = "Legendary", Color = Color3.fromRGB(255, 190, 60)},
    },
    Callback = function(value)
        print("Selected rarity:", value)
    end,
})

Tab:CreateText({
    Name = "Reward details",
    Text = "This paragraph grows with wrapped text and can contain Roblox GUI instances.",
    Instances = {
        {
            ClassName = "Frame",
            Size = UDim2.new(1, 0, 0, 34),
            BackgroundTransparency = 1,
            Children = {
                {
                    ClassName = "TextLabel",
                    Text = "Instance content follows the paragraph width.",
                    TextSize = 14,
                    TextColor3 = Color3.fromRGB(255, 255, 255),
                    BackgroundTransparency = 1,
                },
            },
        },
    },
})
```

`ThemeAnimation` accepts either one theme name or an ordered table of theme names. `TransitionTime` accepts seconds as a number or a string such as `"5 seconds"`. Dropdown options remain backward-compatible with plain strings; table options use `Name`/`Text` plus an optional `Color`/`LabelColor`.


## Dropdown colors and custom sidebar width

```lua
local Window = Rayfield:CreateWindow({
    Name = "Custom Sidebar Demo",
    SidebarLayout = true,

    -- Accepts a number or a string such as "240 px".
    SideBarWidth = "240 px",
})

local Tab = Window:CreateTab({
    Name = "Rewards",
})

Tab:CreateDropdown({
    Name = "Rarity",
    Options = {
        {Label = "Common", LabelColor = Color3.fromRGB(190, 190, 190)},
        {Label = "Rare", LabelColor = Color3.fromRGB(80, 160, 255)},
        {Label = "Epic", LabelColor = Color3.fromRGB(190, 90, 255)},
        {Label = "Legendary", LabelColor = Color3.fromRGB(255, 190, 60)},
    },
    Callback = function(value)
        print(value)
    end,
})

-- A separate map is also supported.
Tab:CreateDropdown({
    Name = "Another rarity list",
    Options = {"Common", "Rare", "Epic", "Legendary"},
    OptionColors = {
        Common = Color3.fromRGB(190, 190, 190),
        Rare = Color3.fromRGB(80, 160, 255),
        Epic = Color3.fromRGB(190, 90, 255),
        Legendary = Color3.fromRGB(255, 190, 60),
    },
})
```

`SideBarWidth` controls the sidebar rail and all of its tab rows. The main content area automatically receives the remaining width, so sections, buttons, toggles, dropdowns, paragraphs, and displays resize with it.
